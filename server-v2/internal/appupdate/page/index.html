How to install Jinsi ya kusakinisha

  1. Tap the button above.Bonyeza kitufe hapo juu.
  2. When the download finishes, tap Open.Upakuaji ukiisha, bonyeza Open.
  3. If the phone asks, allow installing from this app (Chrome), then press Back.Simu ikiuliza, ruhusu kusakinisha kutoka Chrome, kisha rudi nyuma.
  4. Tap Install (or Update).Bonyeza Install.

Salio updates itself. When a new version is ready a bar appears in the app; on Wi-Fi it downloads by itself. Your records stay on the phone while it updates.
